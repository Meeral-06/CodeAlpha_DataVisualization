# CodeAlpha_DataVisualization

## Objective
Transform raw book data into compelling visual formats using Matplotlib and Seaborn.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visuals Created
- Bar chart: Number of books by rating
- Histogram: Book price distribution
- Box plot: Price distribution by rating
- Scatter plot: Price vs Rating
- Heatmap: Correlation between price and rating
- Dashboard: Combined view of all key visuals

## How to Run
```bash
pip install -r requirements.txt
python visualize_books.py
